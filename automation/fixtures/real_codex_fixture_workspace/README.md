# Disposable Real Codex Fixture Workspace

This directory exists only for the Phase C1 controlled Codex test. It contains a fictional input, narrowed non-secret contract/schema copies, a fixed prompt template, and dedicated local outputs.

Forbidden here:

- real people, cases, backlog entries, or production artifacts;
- credentials, API keys, tokens, environment dumps, or private configuration;
- media, downloads, generated assets, or platform data;
- links to or copies from any real Cold Truth case folder.

The Codex process must use this directory as both its process working directory and `--cd` directory. Its only permitted product is the schema-constrained last-message JSON written by the CLI into the assigned attempt output folder.

This workspace is disposable. A successful test does not authorize research, production, media work, or publishing.
